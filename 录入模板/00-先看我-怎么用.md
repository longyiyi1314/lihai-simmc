# 准备工作：把这几张表填了就能开工

> 目标：在 GitHub 上做一个站，打开就能看国家/公会的**成员名单、职位层级、各人简介**。
> 现在这个文件夹是空的，站要用的数据还没有，所以先请你填下面几样。

## 三条路，选最省事的

**A. 直接填 CSV（最推荐）**
用 Excel 打开 `02-成员名单.csv`、`03-职位层级.csv`、`04-职务分工.csv`，填完保存成 **CSV UTF-8（逗号分隔）**，放回这个文件夹。
里面有示例行，填之前把示例行删掉。

**B. 已经有现成的表格（腾讯文档 / 飞书 / Excel）**
不用重填，直接导出一份给我，列名对不上我来转。哪怕是"游戏ID + 职位 + 一句简介"三列也能用。

**C. 什么都没有，先看效果**
那就不用填，我先用 6 个假成员做一版能打开的样例站，你看样式满意了再往里换真人。

## 填的时候三个注意

1. **职位 ID 和职务 ID 要对得上**：成员表里写的「职位ID」必须能在职位表里找到，「职务ID」必须能在职务表里找到，否则构建会报错（这正是防写错的设计）。
2. **多个值用竖线 `|` 隔开**，不要用逗号（逗号在 CSV 里是分列符）。
3. **`id` 这一列是网址用的**，只能小写英文 + 数字 + 短横线，比如 `chen-mo`。填好就不要再改，改了旧链接会失效。中文名放「展示名」。

## 还有两件只有你能做的事（不是填表）

1. **GitHub 授权**：这个项目在 Git Forge 里一个账号都没授权，而且推送保护是开着的 —— 在界面**右侧栏 → Git Credentials** 里授权一次 GitHub 账号，否则我推不上去。
2. **GitHub 用户名 + 仓库名**：决定了最终网址长什么样（`https://用户名.github.io/仓库名/`）。写在 `01-组织信息.md` 里。

填完把文件丢回 `C:\exe\github仓库\录入模板\`，或者直接把内容贴在对话里都行。
